# English Translation Review

Status: Draft for approval — not yet applied to the website  
Tone: Concise, professional portfolio English for international recruiters and design studios

## Translation conventions

- 김예은 → **Yeeun Kim**
- 카드뉴스 → **carousel posts** (rather than the Korea-specific literal term “card news”)
- 기획안 → **content brief**
- 모형 → **scale model**
- 공간 투시도 → **interior perspective**
- 본관 / 신관 → **main building / annex**
- 층 표기 → **B1, 1F–9F**
- Identical strings repeated in source data use the same translation.
- Source filenames and internal layer names that visitors never see will remain unchanged. Any Korean `alt` text attached to those images will still be translated for accessibility.
