# PLEATS MAMA STORE 상세 페이지 설계

## 목적

`work, with care.` 목록의 `PLEATS MAMA STORE`에서 별도 상세 페이지로 이동할 수 있게 한다. 상세 페이지는 `ref.figma/pleats mama.fig`의 가장 왼쪽 프레임(`24:5`)을 기준으로 재현한다. 이번 단계에서는 정적 레이아웃까지만 구현하고 Perspective 애니메이션은 후속 작업으로 남긴다.

## 기준과 범위

- 기준 Figma 프레임: `24:5`, 원본 크기 `1440 × 4097`
- 웹 캔버스 크기: `1440 × 3600`
- 모든 콘텐츠의 x/y/width/height 값은 원본 Figma 좌표를 유지한다.
- 높이만 3600px로 줄이고 `overflow: hidden`으로 하단 초과 영역을 자른다. 축소된 높이에 맞춰 다른 콘텐츠를 이동하지 않는다.
- Figma의 가장 왼쪽 프레임에 있는 전체 정적 레이아웃을 구현한다.
- 오른쪽에 놓인 다른 세 프레임은 Perspective 이미지 변형 후보이므로 이번 페이지에 포함하지 않는다.
- Perspective 애니메이션은 이번 범위에서 제외한다.

## 구현 방식

하이브리드 고정 캔버스 방식을 사용한다.

- 페이지 구조, 텍스트, 내비게이션은 의미 있는 HTML 요소로 만든다.
- Figma에 포함된 원본 비트맵은 파일에서 추출해 `assets/pleats-mama/`에 저장한다.
- 복잡한 도식과 벡터는 원본 형태를 보존할 수 있는 이미지/SVG 단위로 배치한다.
- 모든 시각 요소는 `pleats-mama.css`에서 Figma 좌표를 절대 위치로 적용한다.
- Perspective 이미지는 후속 애니메이션을 위해 별도의 `<img>` 요소와 전용 클래스로 분리한다.
- 기존 상세 페이지와 동일하게 `min-width: 1440px`, 중앙 정렬 고정 캔버스를 사용한다.

## 첫 화면

- 배경색은 Figma 프레임의 `#fffaf9` 계열 값을 그대로 사용한다.
- 메인 외관 이미지는 Figma 노드 `24:7`을 사용한다.
  - 위치: `x 0`, `y 318.0805`
  - 크기: `1440 × 806.5742`
- 이미지와 배경을 연결하는 그라데이션은 별도 HTML 도형으로 둔다.
  - Figma 노드: `24:8`
  - 위치: `x 0`, `y 305.5805`
  - 크기: `1440 × 194.1272`
  - 방향: 위쪽 불투명 → 아래쪽 투명
  - 색상: `#fffaf9` → `rgba(255,250,249,0)`
- 그라데이션의 위치, 크기, 색상, 방향은 임의로 보정하지 않는다.

## 콘텐츠 레이아웃

- Intro, Concept Design, User Experience Design, Perspective image 섹션은 왼쪽 기준 프레임의 원본 순서와 좌표를 유지한다.
- 텍스트 내용, 글꼴 크기, 굵기, 색상, 줄바꿈은 Figma 값을 기준으로 구현한다.
- 이미지의 비율, 모서리 반경, 크롭 방식도 Figma 노드 값을 유지한다.
- 3600px를 넘어가는 요소는 좌표를 변경하지 않고 캔버스 경계에서 자연스럽게 잘린다.

## Perspective 기준 이미지

- 왼쪽 프레임의 노드 `24:130`을 기준 이미지로 사용한다.
- 위치: `x 149.6328`, `y 3036.0779`
- 크기: `814.89 × 458.4875`
- 모서리 반경: `10px`
- Figma 이미지 해시: `59ef942f17f13c16104725ddd7c4a34137a5565c`
- 이번 단계에서는 정적 이미지로 표시한다. 후속 애니메이션 구현 시 이 요소만 교체하거나 변형할 수 있어야 한다.

## 이동과 내비게이션

- `PLEATS MAMA STORE` 항목은 `pleats-mama.html`로 이동하는 링크로 변경한다.
- `index.html`과 `spatial.html` 양쪽에서 같은 상세 페이지로 이동한다.
- 상세 페이지의 상단 포트폴리오 내비게이션은 기존 상세 페이지 패턴을 따라 `index.html#home`, `#work`, `#about`, `#contact`로 연결한다.

## 파일 구성

- `pleats-mama.html`: 페이지의 의미 구조와 모든 정적 요소
- `pleats-mama.css`: 1440 × 3600 고정 캔버스 및 Figma 좌표 스타일
- `assets/pleats-mama/`: Figma에서 추출한 원본 이미지와 필요한 도식 자산
- `tests/pleats-mama-page.test.cjs`: 이동 경로, 캔버스 크기, 그라데이션, 주요 Figma 좌표와 자산 검증
- `index.html`, `spatial.html`: PLEATS 상세 페이지 링크 반영

## 검증

- 테스트를 먼저 작성하고 현재 구현에서 실패하는지 확인한다.
- PLEATS 항목이 두 포트폴리오 페이지에서 `pleats-mama.html`로 연결되는지 검증한다.
- 캔버스가 정확히 `1440 × 3600`이고 `overflow: hidden`인지 검증한다.
- 메인 이미지, 그라데이션, Perspective 이미지의 좌표와 크기가 Figma 값과 일치하는지 검증한다.
- 추출한 모든 이미지 경로가 실제 파일로 존재하는지 검증한다.
- 가능하면 로컬 렌더링을 캡처해 Figma 왼쪽 프레임과 시각적으로 비교한다.

## 오류 및 대체 처리

- 이미지 자산이 누락되면 빈 대체 이미지를 사용하지 않고 테스트를 실패시켜 누락을 드러낸다.
- 외부 네트워크 없이 로컬 자산만으로 핵심 레이아웃이 표시되게 한다.
- 사용자의 모션 감소 설정에서는 현재 단계에 애니메이션이 없으므로 별도 움직임을 만들지 않는다.
